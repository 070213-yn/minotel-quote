# minotel 見積書発行ツール

ブラウザ上で見積書を作成し、PDFとしてダウンロードできるツールです。
（個人事業主 minotel / 近藤信吾 用）

## 使い方
1. 公開URLを開く（GitHub Pages）
2. 宛先・件名・明細などを入力
3. 右側のプレビューに即反映される
4. 「PDFを発行（ダウンロード）」ボタンでPDFが保存される

## 特徴
- インストール不要、ブラウザだけで動作
- 数量×単価＝金額、小計、消費税10%、合計（税込）を自動計算
- 発行者情報・振込先はブラウザに記憶（次回も自動入力）
- 1ファイル完結（index.html）

## 技術メモ
- PDF生成: html2pdf.js（html2canvas + jsPDF）をCDN読み込み
- 日本語はブラウザのフォントでそのまま描画されるため文字化けしない
- レイアウトはA4縦、既存Excel見積書フォーマットに準拠
